# gh-saksham

Saksham Arora's card in your terminal.

```
gh extension install saksham10arora-dotcom/gh-saksham
gh saksham
```

or with Homebrew:

```
brew install saksham10arora-dotcom/tap/saksham
saksham
```

Other ways in: `curl -sL saksham.digital`, `npx saksham-arora`, and an MCP server at `https://saksham.digital/mcp`.
